# Hot or Not

A modern take on the classic Hot or Not site.

- Upload your real photo to enter
- Rate others as Hot or Not
- See your score and the leaderboard
- Seeded with 20 realistic AI-generated portraits (11 men, 9 women) for cold start
- Seed accounts can be removed once 20+ real users join

## Run locally
Open `index.html` in a browser. The seed photos live in the `images/` folder (add the generated JPGs from the build to make portraits appear).

## Deploy
Static site — works on Vercel, Netlify, or any static host. Include the `images/` directory.
